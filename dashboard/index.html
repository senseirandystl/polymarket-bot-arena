Portfolio Capital Allocation

Split the shared bankroll across active bots. When enabled, each bot Kelly-sizes against bankroll × weight (weights sum to 1) instead of the full pool — so correlated bots no longer each size as if they own the whole bankroll. Methods: equal, sharpe, expectancy, or kelly_portfolio (expectancy/variance, correlation-shrunk). Rebalances every 30 min and on regime change. Pin a bot with a manual weight; free capital is redistributed by the method. Arena picks up changes within seconds.
