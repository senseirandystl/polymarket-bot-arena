Exchanges

Paper and live both obey these toggles. Off stops discovery, evaluation, and fills on that exchange within a few seconds. Both on by default.

Paper Balance

Shared virtual USDC bankroll for paper mode only. Enter the balance you want — it tops the bankroll up to that amount (history preserved). Bankroll is shown read-only on Overview (Bankroll / Kelly chip). Live mode uses the configured wallet USDC balance.

Kelly Fraction

Fraction of full Kelly used for every trade. 0.25 = quarter-Kelly (default). Changes apply within seconds; current value is mirrored on Overview (Bankroll / Kelly chip).

Paper-eval tandem

Paper eval: cluster open so every bot can fill the same (market, side) and grow sample size. Dollar exposure cap still binds. Restore max-bots=1 / one-trade-per-tick / pile-in ON before live.

Pile-in EV gate

After one bot already holds a (market, side), additional bots must clear a higher edge bar (progressive EV) before adding exposure — unless confidence is very high (≥ conf bypass). Not a hard bot-count ban. Paper-eval default OFF. Knobs: min edge / step / conf bypass in config.

Directional window lock

When ON, after any directional bot fills on a market, no other directional bot may open that same window (one thesis per market). Default OFF. Paper-eval also leaves one-trade-per-tick and max-bots-per-side off (see tandem pack above). Toggle for stricter long-run concentration without a restart.

Risk Engine Limits

Editable risk thresholds. Changes apply within ~15s (or immediately via Save limits / Re-eval on Overview). Status and per-bot risk live on the Overview page.

Soak report

Snapshot of live P&L, WR, BE gap by bot/side, lane monitor, core-lane tuner, regime adapt multipliers, and skip funnel. Sends to your configured notification channel (Telegram). Safe to run anytime — read-only on trades.

Portfolio Capital Allocation

            

                Split the shared bankroll across active bots. Default: On — each bot Kelly-sizes against
                bankroll × weight (weights sum to 1) instead of the full bankroll, so correlated
                bots no longer each size as if they own the whole bankroll. Off restores legacy full-bankroll Kelly.
                Methods: equal, sharpe, expectancy, or kelly_portfolio
                (expectancy/variance, correlation-shrunk). Rebalances every 30 min and on regime change.
                Pin a bot with a manual weight; free capital is redistributed by the method.
